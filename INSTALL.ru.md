# Установка и сборка Dubbly

## Быстрый старт (Windows)

Дважды щёлкните `start.bat`. При первом запуске он при необходимости поставит Python 3.12 (через winget), создаст окружение, скачает библиотеки и откроет программу. Дальше она открывается сразу.

## Запуск из исходников

Нужен Python 3.11 или 3.12.

```
pip install -r requirements.txt
python main.py
```

## Видеокарта NVIDIA

Включена по умолчанию. При первом запуске на компьютере с видеокартой Dubbly сам скачает
библиотеки CUDA (cuBLAS и cuDNN, около 1 ГБ) с PyPI в свою папку данных. Опцию можно отключить
в окне программы. Без видеокарты или без этих библиотек работает процессор.

## Язык интерфейса

Интерфейс доступен на русском, английском, украинском, испанском, немецком, французском, португальском,
итальянском, польском, турецком и китайском. Язык выбирается в шапке окна (по умолчанию «Как в системе»),
переключение мгновенное и не сбрасывает настройки. Сообщения о ходе работы и ошибки идут на том же языке.
Переводы сделаны с помощью машинного перевода и не проверены носителями языка: исправления приветствуются.

Чтобы добавить язык: скопируйте `assets/locales/en.json`, переведите значения (подстановки вроде `{name}`
сохраняйте), добавьте язык в `LANGS` в `vt/i18n.py` и проверьте файл командой `python tools/check_locales.py`.

## Шрифт

В Dubbly встроен JetBrains Mono (лицензия SIL Open Font License, текст в `assets/fonts/OFL.txt`).
Чтобы использовать другой шрифт, положите файл `.ttf` или `.otf` в папку `fonts`: рядом с `start.bat`
(при запуске из исходников) или в папку данных программы, подпапка `fonts`
(`%LOCALAPPDATA%\Dubbly\fonts`, а если в имени пользователя есть не латинские буквы,
то `C:\Users\Public\Dubbly\fonts`). В шрифте обязательна кириллица. Свои шрифты не входят
в репозиторий и установщик: у многих лицензия запрещает распространение. Чтобы вернуться
к JetBrains Mono, уберите файл из папки.

## Свои голоса

Можно добавить любой голос Piper: нажмите **Добавить…** рядом со списком голосов и выберите файл `.onnx`
(парный файл `.onnx.json` должен лежать в той же папке). Голоса есть, например, на
https://huggingface.co/rhasspy/piper-voices, а можно обучить собственный. Программа копирует пару файлов
в свою папку данных (`voices`), определяет язык по настройкам голоса и показывает голос в списке
этого языка с пометкой «(свой)». **Удалить** убирает голос из программы, исходные файлы остаются на месте.
Проверяйте лицензию каждого используемого голоса: у некоторых запрещено коммерческое использование.

## Сборка .exe

На Windows запустите `build.bat`, программа появится в `dist\Dubbly\`.

Без установки чего-либо у себя можно собрать через GitHub: загрузите файлы проекта в репозиторий, откройте вкладку **Actions**, выберите **Build Windows exe** и нажмите **Run workflow**. Когда сборка закончится, скачайте архив в разделе **Artifacts** на странице запуска и распакуйте его: внутри лежит `Dubbly-Setup.exe`. Запустите его, и Dubbly установится (ярлыки в меню «Пуск» и на рабочем столе, удаление через «Приложения»). Новая версия, установленная поверх старой, сохраняет настройки и скачанные модели.
